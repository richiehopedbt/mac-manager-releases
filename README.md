# Mac Manager downloads

Signed and notarised builds of **Mac Manager**, the disk, cleanup and system monitor utility for macOS 27 by DigitalHope.

**Get it from [digitalhopeltd.com/macmanager](https://digitalhopeltd.com/macmanager).** Each version is attached to a [release](https://github.com/richiehopedbt/mac-manager-releases/releases), and Mac Manager updates itself from there.

Mac Manager is free to download and look around. Cleaning, tidying, offloading and uninstalling need a subscription, which starts with a free trial.
